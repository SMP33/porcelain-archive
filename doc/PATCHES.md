# Патчи схемы БД
- Патчи схемы БД, не покрытые IF NOT EXISTS в create_tables.sql, регистрируются в porcelain_archive/database/patch.py, каждый - под своим uuid
- Применённые патчи отмечаются вставкой uuid в таблицу patch
- Патч выполняется, только если его uuid отсутствует в таблице patch, и выполняется в одной транзакции: проверка условия патча → список нужных SQL-команд → вставка uuid патча в конец списка
- Если условие патча не требует изменений в БД, список содержит только вставку uuid
- patch_tables.sql не используется - патчи, уже применённые на всех известных БД, переносятся напрямую в create_tables.sql, а не в patch.py
