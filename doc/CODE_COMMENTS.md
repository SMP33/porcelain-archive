# Comments in code
- Комментарии должны быть максимально короткими.
- Комментарий должен описывать саму сущность (что она делает/представляет), а не контекст её использования.
- Не указывать причину, по которой был написан код или комментарий.
- Не указывать, где и как сущность будет применяться в проекте.
- Избегать очевидных комментариев, дублирующих то, что уже понятно из кода.
- Коментарии не должны быть не первого лица. Вместо "Добавляем действие" должно быть "Добавление действия"
