# Don't
- backend - агент не может менять без прямого указания, но может предлагать свои изменения
- Агент не может без запроса менять backend, если меняется frontend
- Агент не может без запроса менять sql файл базы данных
- Не требуется отслеживать текущее состояние БД и пробовать ее редактировать при изменении sql файлов
- Не требуется делать тестовых запусков без запроса на это
- Не делать операций, которые потребуют подтверждения от пользователя
