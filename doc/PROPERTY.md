# Указатели
- Привязаны к документу и имеют тип
- tag - уникальное имя на латиницев нижнем регистре, может содержать _, задается только один раз при создании
- title - отображаемое имя, может меняться
- description - описание, появляемое в тултипе при наведении, может меняться
- is_editable - возможно ли редактирование списка значений, может меняться
- is_usable - возможно ли добавлять параметр в документ и менять его значение, может меняться
- is_visible - видно ли на странице документа и в списке указателей и в индексации на странице поиска, может меняться
- type - тип, задается один раз при создании

## Типы указателей
- string - редактируемая строка, не индексируется на странице поиска
- bool - true/false
- combobox - выбор одного значения из существующих
- multickeckbox - выбор нескольких значений из существующих
- для combobox и multickeckbox - Доступные значения добавляются в document_property с document_id = NULL. Для документа можно либо ввести новое значение, тогда оно добавится и для document_id, и для NULL, а можно использовать существующее

## Переводы указателей
- property_translate - для того, чтобы на значения можно было ссылаться из кода, есть механизм перевода указателей 
- значения из этой таблицы в пользовательском интерфейсе должны отображаться как переведенные
